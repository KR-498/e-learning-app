Funkcje w języku Kotlin

Funkcje są fundamentalnym budulcem każdego programu w Kotlinie. Służą do organizowania kodu w reużywalne i logiczne bloki.

1. Definiowanie funkcji

Każdą funkcję w Kotlinie deklarujemy za pomocą słowa kluczowego fun. Po nim następuje nazwa funkcji, nawiasy okrągłe (w których mogą znaleźć się parametry) oraz klamry otwierające ciało funkcji.

fun sayHello() { println("Cześć, programisto!") }

2. Parametry funkcji

Parametry definiujemy wewnątrz nawiasów okrągłych. W Kotlinie obowiązuje zasada nazwa: Typ. Każdy parametr musi mieć jasno określony typ danych. Wszystkie parametry funkcji są domyślnie niemodyfikowalne (działają jak val).

fun printUserAge(name: String, age: Int) { println("$name ma $age lat.") }

3. Wartości zwracane

Jeśli funkcja ma zwracać wynik, jej typ określany jest **po dwukropku** za nawiasem z parametrami. Do zwrócenia konkretnej wartości używamy słowa kluczowego return.

fun multiply(a: Int, b: Int): Int { return a * b }
💡 Typ Unit: Jeśli funkcja nie zwraca żadnej wartości, jej domyślnym typem zwracanym jest Unit (odpowiednik void z Javy). Dopisywanie go na końcu deklaracji funkcji jest opcjonalne.

4. Funkcje jednougrupowe (Single-Expression functions)

Gdy funkcja zwraca pojedyncze wyrażenie, możemy pominąć klamry oraz słowo return, stosując znak równości =.

fun square(x: Int): Int = x * x

⚡ Szybka powtórka: Fiszki pojęciowe

Kliknij fiszkę, aby obrócić ją i sprawdzić znaczenie najważniejszych pojęć:

fun

Słowo kluczowe służące do deklarowania funkcji w języku Kotlin.

Unit

Typ zwracany przez funkcje, które nie zwracają żadnej użytecznej wartości (odpowiednik void).

Parametry

Zmienne przekazywane do funkcji w nawiasach okrągłych. Są domyślnie niemodyfikowalne (val).

Single-Expression

Funkcja jednougrupowa. Pomija klamry i słowo return, używając znaku równości =.
